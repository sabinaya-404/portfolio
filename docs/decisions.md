# Design Decisions

## Architectural Design Records
 This document records the key technical and design choices made while building this portfolio, explaining the rationale behind each decision. 

## 1. Why Neo-Brutalism?
 Just wanted to try different theme and less generic than a typical developer portfolio.

 ## 2. Why Plain CSS?
 I want to learn CSS instead of relying on Tailwind. Didn't know CSS is this powerful, brah

 ### 3. Why Modular CSS per Component?
Splitting stylesheets alongside each `.jsx` file keeps each section self-contained, easier to debug, and prevents massive 600+ line CSS files.
